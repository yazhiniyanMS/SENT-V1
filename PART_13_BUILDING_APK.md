## PART 13 — BUILDING APK

### Debug APK
Useful for testing and development.

#### Via Android Studio
1. Select any build variant (debug is default)
2. Click Build > Build Bundle(s) / APK(s) > Build APK(s)
3. Wait for build to complete
4. Click "Locate" in the notification to find the APK
5. APK location: `app/build/outputs/apk/debug/app-debug.apk`

#### Via Command Line
```bash
cd sentinel_x
flutter build apk --debug
```
APK location: `build/app/outputs/flutter-apk/app-debug.apk`

### Release APK
For distribution and performance testing.

#### Via Android Studio
1. Click Build > Build Bundle(s) / APK(s) > Build Bundle(s)/APK(s)
2. Select APK radio button
3. Choose release build type
4. Click Finish
5. Wait for build to complete
6. Locate the APK in the notification or at:
   `app/build/outputs/apk/release/app-release.apk`

#### Via Command Line
```bash
cd sentinel_x
flutter build apk --release
```
APK location: `build/app/outputs/flutter-apk/app-release.apk`

### APK Size Optimization
To reduce APK size:
1. Use `--split-per-abi` to create separate APKs for different architectures:
   ```bash
   flutter build apk --release --split-per-abi
   ```
   This creates:
   - `app-armeabi-v7a-release.apk`
   - `app-arm64-v8a-release.apk`
   - `app-x86_64-release.apk`

2. Enable code shrinking and resource optimization (in `build.gradle`):
   ```gradle
   buildTypes {
       release {
           // TODO: Add your own signing config for release builds.
           signingConfig signingConfigs.debug
           minifyEnabled true
           useProguard true
           proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
       }
   }
   ```

### Installing the APK
#### On Device via ADB
```bash
adb install build/app/outputs/flutter-apk/app-release.apk
```

#### Via Android Studio
1. Drag and drop APK onto emulator window
2. Or use File > Import > APK

### Important Notes
1. **Debug vs Release**: 
   - Debug APK includes debugging symbols and is larger (~30-50MB)
   - Release APK is optimized and smaller (~15-25MB)
   - Release APK has better performance

2. **Signing**:
   - Debug APK is signed with a debug key (generated by Android Studio)
   - Release APK should be signed with your own key for distribution
   - For testing, the default release signing works fine

3. **App Size Considerations**:
   - Most of the size comes from the Flutter engine (~12MB)
   - Video asset adds to APK size (consider using network video for smaller APK)
   - Assets are included in the APK (keep demo video reasonable size)

4. **Testing Recommendations**:
   - Test debug APK on device during development
   - Test release APK before distribution to ensure performance
   - Check that all features work in both build types

5. **OTA Updates**:
   - For future versions, consider implementing in-app updates
   - Or use platform-specific distribution (Google Play Store, etc.)

### Build Commands Reference
```bash
# Clean build
flutter clean

# Get dependencies
flutter pub get

# Build debug APK
flutter build apk --debug

# Build release APK
flutter build apk --release

# Build release APK split by ABI
flutter build apk --release --split-per-abi

# Build app bundle (for Google Play Store)
flutter build appbundle --release

# Run a specific device
flutter run -d <device-id>

# See connected devices
flutter devices

# View build output (helpful for debugging)
flutter build apk --verbose
```
